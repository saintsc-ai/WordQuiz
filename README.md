# 한글 워들 (WordQuiz)

한글 낱말을 **자모 단위**로 맞히는 웹 게임. 5번 안에 정답 명사를 찾으면 이깁니다.

```
안녕  →  ㅇ ㅏ ㄴ ㄴ ㅕ ㅇ   (6칸)
```

## 규칙

1. 자모 **5 · 6 · 7 · 8 · 9개** 중 길이를 고릅니다.
2. 화면의 간략화 자판으로 자모를 한 칸씩 입력합니다.
3. 자모가 모두 일치하면 승리.
4. 추측하는 단어도 **사전에 있는 명사**여야 합니다.
5. 채점
   - 🟩 자모와 자리가 모두 맞음
   - 🟨 그 자모는 들어있지만 자리가 다름
   - ⬜ 정답에 없는 자모
6. 기회는 **5번**.

## 자판과 자모 분해

자판은 두벌식에서 쌍자음과 복합모음 키를 뺀 **24키**입니다.

| | 키 |
|---|---|
| 자음 14 | ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅅ ㅇ ㅈ ㅊ ㅋ ㅌ ㅍ ㅎ |
| 모음 10 | ㅏ ㅑ ㅓ ㅕ ㅗ ㅛ ㅜ ㅠ ㅡ ㅣ |

나머지 자모는 전부 이 24키의 조합으로 입력합니다.

| 종류 | 예 |
|---|---|
| 쌍자음 | ㄲ = ㄱㄱ, ㅆ = ㅅㅅ |
| 겹받침 | ㄺ = ㄹㄱ, ㅄ = ㅂㅅ |
| 복합모음 | ㅐ = ㅏㅣ, ㅘ = ㅗㅏ, ㅢ = ㅡㅣ |

따라서 `꽃` = ㄱㄱㅗㅊ(4), `사과` = ㅅㅏㄱㅗㅏ(5) 처럼 셉니다.
3키가 필요한 **ㅙ, ㅞ** 만 지원하지 않으며 해당 단어는 사전에서 제외됩니다.

> 자모열이 단어와 항상 1:1은 아닙니다. `ㄱㅏㄱㄱㅏ` 는 `가까` 와 `각가` 둘 다에 해당합니다.
> 사전을 자모열로 색인하므로 이런 단어는 모두 추측으로 인정됩니다.

## 링크로 공유하기

판이 끝나면 **링크 복사** 로 지금 푼 단어를 그대로 담은 주소를 얻습니다.

```
https://.../#p=sOrasf_usf3S
```

정답 단어를 UTF-8 → XOR → base64url 로 감싼 값이라 주소만 봐서는 알 수 없습니다.
암호가 아니라 눈에 띄지 않게 하는 정도입니다. 링크를 연 사람은 같은 단어를 풀게 되고,
제목이 **공유받은 단어** 로 바뀝니다. ↻ 를 누르면 무작위 새 단어로 돌아갑니다.

**결과 공유** 는 이모지 격자와 링크를 함께 내보냅니다. 모바일에서는 공유 시트가 뜹니다.

### 직접 출제

머리말의 **✎** 를 누르면 낼 단어를 직접 고를 수 있습니다. 한글로 치면
사전에 있는 명사인지, 자모가 5 ~ 9칸인지 바로 확인해 주고 링크를 만들어 줍니다.
추측 허용 목록(명사 전체)에 있으면 되므로 정답 후보보다 훨씬 넓게 낼 수 있습니다.

```
한글 워들 · 자모 6칸  3/5
⬜🟩🟨⬜⬜🟩
🟩🟩⬜🟨⬜🟩
🟩🟩🟩🟩🟩🟩
https://.../#p=sOrasf_usf3S
```

## 실행

의존성도 빌드 단계도 없습니다.

```bash
python -m http.server 8000
# http://localhost:8000
```

`index.html` 을 브라우저에서 직접 열어도 동작합니다. (데이터를 `fetch` 가 아니라
`<script>` 주입으로 읽기 때문)

## 단어 데이터 다시 만들기

`data/*.js` 는 이미 커밋되어 있으므로 평소에는 실행할 필요가 없습니다.
사전을 갱신하려면:

```bash
python tools/fetch_krdict.py   # 원본 zip 내려받기 (약 84MB, data/raw/)
python tools/build_dict.py     # data/words-N.js, answers-N.js 생성
```

| 자모 수 | 추측 허용 | 정답 후보 |
|---:|---:|---:|
| 5 | 4,703 | 1,165 |
| 6 | 6,996 | 1,547 |
| 7 | 3,346 | 875 |
| 8 | 4,466 | 1,012 |
| 9 | 3,856 | 817 |

- **추측 허용**: 한국어기초사전의 명사 전체 중 해당 길이인 것
- **정답 후보**: 그중 어휘등급이 초급 · 중급인 것

## 구조

```
index.html          화면 뼈대
css/style.css       다크 테마
js/jamo.js          한글 ↔ 자판 입력열 변환
js/dict.js          단어 데이터 로딩 · 검증
js/game.js          게임 상태와 채점 (DOM 비의존)
js/ui.js            렌더링과 입력 처리
tools/              사전 내려받기 · 가공 스크립트
data/               생성된 단어 데이터
```

`js/jamo.js` 의 `EXPAND` 와 `tools/build_dict.py` 의 `EXPAND` 는 항상 같아야 합니다.
